# Governance of this fork

This fork is maintained through the `mlnomadpy/agentbox` repository. Its
maintainers decide what merges and what is released here. Upstream retains its
own project direction and review process; this fork does not speak for upstream.

Propose significant design changes in an issue with the problem, alternatives,
and acceptance criteria. Record consequential decisions with the implementing
pull request and update the relevant documentation. Maintainers may request a
smaller scope or decline changes with an explanation. Be respectful, discuss
technical evidence, and avoid personal attacks.

A passing workflow is necessary evidence, not automatic approval to merge.
Maintainers review behavior, permissions, dependencies, and migration impact.
Release publication and repository administration remain maintainer actions.
Contributors do not need release credentials. See [CONTRIBUTING.md](CONTRIBUTING.md).
