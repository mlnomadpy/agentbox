# Support

For this fork, use [GitHub issues](https://github.com/mlnomadpy/agentbox/issues)
for reproducible bugs, feature proposals, and documentation gaps. Include the
commit, operating system, Node version, affected mode, and minimal steps.
Remove secrets and personal content from logs and screenshots.

For upstream releases, use the [upstream repository](https://github.com/savannahfeder/agentbox).
See [development setup](docs/development.md) before reporting installation problems.
Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
Support and review are provided as maintainer availability permits.
